# API-тесты для Stellar Burgers

Набор автотестов для проверки REST API проекта Stellar Burgers


## Что покрыто тестами

- регистрация пользователя (все ключевые сценарии)
- логин (валидный и невалидный)
- изменение данных пользователя (авторизованно / неавторизованно)
- создание заказа (разные комбинации: с ингредиентами, без, с ошибками)
- получение заказов пользователя (с авторизацией и без)

## Как запустить тесты

# Установить зависимости
pip install -r requirements.txt

# Запуск всех тестов
PYTHONPATH=. pytest --alluredir=allure-results

# Просмотр отчёта Allure
allure serve allure-results
